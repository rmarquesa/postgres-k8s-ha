04 / RECOVERY PATH

Designed for the incident,
not the architecture slide.

    Detect

    Actionable alerts identify primary, replica, WAL, backup and saturation failures.

  2. 02
    Fence

    Prevent split-brain before reconnecting an isolated node or old write path.

  3. 03
    Recover

    Promote, reconnect or create a new PITR cluster from an immutable archive identity.

  4. 04
    Prove

    Verify commits, timelines, application queries and measured RPO/RTO.
